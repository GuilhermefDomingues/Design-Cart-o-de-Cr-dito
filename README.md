# Modern Bank Card

Projeto desenvolvido com HTML e CSS que simula um cartão bancário moderno. O componente apresenta informações do cartão, chip, bandeira e dados do titular em uma interface elegante inspirada em aplicativos financeiros.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts (Poppins)

## ✨ Funcionalidades

- Cartão bancário moderno
- Layout responsivo
- Imagem de fundo personalizada
- Exibição do chip
- Nome do titular
- Número do cartão
- Data de validade
- Efeitos visuais modernos
- Sombras e gradientes

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
